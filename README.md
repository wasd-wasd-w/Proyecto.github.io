# Bitácora

Inicio: Comencé definiendo el proyecto que quería presentar en la página web, que fue el tótem que hicimos el primer año de la carrera, ya que fue mi proyecto favorito debido a todo lo que aprendí haciéndolo.

Diseño: Luego pensé en el diseño de la página, cómo podría presentar el proyecto visualmente. Después se realizó el prototipo en Figma, definiendo la distribución de elementos, los colores y la tipografía.

Desarrollo html y css: Traslado el diseño a código, usando html para estructurar la página y css para trabajar los colores, tipografía y posiciones de elementos. Utilicé la ayuda de IA para realizar el css.

Ajustes: Se realizaron cambios en la distribución, tipografía, se incorporaron las imágenes y se ajustaron los elementos como la barra de navegación fija y el pie de página.
